libobjc-wasm implements the Objective-C runtime ABI and public API of Apple's
objc4 runtime (https://github.com/apple-oss-distributions/objc4) so that code
compiled for that runtime links and runs on WebAssembly. The metadata layouts
and the declarations in runtime/include/objc follow objc4's for compatibility;
no objc4 implementation code is used.
